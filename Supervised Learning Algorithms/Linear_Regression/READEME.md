# Linear Regression

This project demonstrates the implementation of a Linear Regression model using Python and Scikit-Learn.

## Concepts Covered

- Understanding supervised learning
- Loading and preparing datasets
- Selecting features and target variables
- Training a simple Linear Regression model
- Making predictions
- Understanding feature shapes in Scikit-Learn

## Libraries Used

- Python
- Pandas
- NumPy
- Scikit-Learn

## Algorithm

Linear Regression is used to predict a continuous numerical value by learning the relationship between input features and the target variable.

## Example

Input Features:
- Videos
- Days
- Subscribers

Target:
- Views

The model learns how these features influence the number of views and predicts views for new data.
